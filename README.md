# Vijay bodkhe android app

Maine aapni ek website banayi varkari shikshan sanstha ke liye. But usmain kahi saari problem hai text main. Mobile par aache se photo nahi dikh rahe. Vo desktop style dikh rhe hai. Organisation ke baare main kaafi information missing hai. Aapko kya karna hai ki main aapko purani website ka code dunga.

1. Apko website main content ko update karna hai  ho sakta hai vo Organisation ki information se match naa karta ho but jo jo information missing hai like about founder, banking details, adress yaa jo bhi missing hai vo sab add kare baaki bad main  usko main edit kar dunga

2. Second photo hero section main crop karke mobile par par image dikhni chahiye. 

3. Tagline muze chahiye jo photo ke center main naa aaye. Vo aap bottom main left side se start kar skate hai aur do cta button admissions and donation 

4. Design ko modern look de jo traditional and modern ka mix ho.

5. Images muze slide show type chahiye 

6. Kahi par bhi inages dikhe to vo attractive anination ke saat present hona chahiye  

7 .  Tagline vidya dadati vinayam yesi tagline add kare aur site hamari default english main. 



Aapka goal hai ki site modern banana. Missing information ko add karna ho sakta hai relevant naa ho. But aapka goal sirf website desig  and presentation main jitna.
